Sistema Backend - Turnos y Reservas (Odontología)

Proyecto backend desarrollado para la facultad utilizando Node.js y Express. implementando una arquitectura en memoria/datos locales.

--------------------------------------------------------------------------------------------
Estructura del proyecto

    config/
        env.config.js
    managers/
        ServiceManager.js
    data/
        services.json
    app.js

.gitignore
README.md
--------------------------------------------------------------------------------------------------
tecnologias utilizadas

Node.js
Express
ES Modules

instalacion y configuracion

descargar la carpeta del repositorio en la pc/mac
npm install
ejecucion con npm start
o npm run dev
